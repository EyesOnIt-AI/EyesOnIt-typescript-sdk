# Common Tasks

## Update SDK For Backend API Change

- Identify backend endpoint and Pydantic model changes.
- Update TypeScript inputs, outputs, elements, validators, and API client methods.
- Update docs with `npm run docs:api` when public API docs change.
- Coordinate with C# SDK, React UI, and documentation repos.

## Add SDK Example

- Use sanitized hostnames and payloads.
- Do not include tokens, license keys, stream credentials, or customer data.
